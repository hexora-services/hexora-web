# HEXORA v3 — კატეგორიებით გახსნა

მთავარი გვერდი ახლა პირდაპირ აჩვენებს **მომსახურებების 12 კატეგორიას** (დიდი ბარათები, ტელეფონზე ორი სვეტი).

## მომხმარებლის გზა

1. აირჩიე **გათბობა და გაგრილება** ან სხვა მთავარი კატეგორია.
2. იხსნება **ცალკე ქვეკატეგორიების ეკრანი** ბარათებით, მაგალითად: „გათბობის ქვაბის ხელოსანი“.
3. ქვეკატეგორიაზე დაჭერით იხსნება **მხოლოდ შესაბამისი ხელოსნების სია**.
4. მომხმარებელი ირჩევს ქალაქს, ხედავს თითოეული ხელოსნის ვიზიტის ფასს და აგზავნის დემო-გამოძახებას.

უკან დაბრუნება მუშაობს გვერდების ღილაკებით და ბრაუზერის Back-ით.

შენარჩუნებულია ხელოსნის ონლაინ რეჟიმი, საკუთარი ვიზიტის ფასის რედაქტირება, შეკვეთები, შეფასებები და ადმინისტრატორის დემო. საწყისში ჩანს მხოლოდ გამოგონილი საცდელი სპეციალისტები. **რეალური ანგარიშები, GPS, მომხმარებლებს შორის სინქრონიზაცია და საბანკო გადახდები ჯერ არ მუშაობს.**

## GitHub Pages-ზე განახლება

`hexora-services/hexora-web` რეპოზიტორიის მთავარ (`main`) საქაღალდეში ძველი ფაილები ჩაანაცვლე `index.html` და `favicon.svg` ფაილებით. `README.md` სურვილისამებრ განაახლე. Pages პარამეტრებს აღარ შეეხო.
