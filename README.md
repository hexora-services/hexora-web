# HEXORA — 24 მომსახურების კატეგორია (V6 კატალოგი)

განახლდა კატალოგი: **24 მთავარი კატეგორია** და **125 ქვეკატეგორია**. მთავარ გვერდზე პირდაპირ ჩანს კატეგორიების ბარათები; ბარათზე დაჭერით იხსნება ქვეკატეგორიები, შემდეგ ხელოსნების სია. საიტი საქართველოს ყველა ქალაქისთვისაა გათვლილი.

## GitHub-ზე ატვირთვა
1. გახსენი ZIP და ამოიღე ფაილები (ZIP-ის პირდაპირ ატვირთვა არ შეიძლება).
2. GitHub-ის `hexora-services/hexora-web` რეპოზიტორიაში აირჩიე `Add file → Upload files`.
3. ატვირთე **ეს რვა ფაილი ერთად**: `index.html`, `account.html`, `account.js`, `real-workers.js`, `firebase-config.js`, `firestore.rules`, `favicon.svg`, `README.md`. ისინი რეპოზიტორიის ზედა დონეზე უნდა იყოს.
4. `Commit changes`.
5. მოითმინე GitHub Pages-ის განახლებამდე და ნახე საიტი.

## აუცილებელია Firebase-ის წესების შეცვლაც
ახალი კატეგორიების არჩევით ხელოსნების რეგისტრაცია მხოლოდ მაშინ იმუშავებს, როდესაც Firebase Console → Firestore → Rules-ში **იგივე განახლებული `firestore.rules`** კოდს ჩასვამ და დააჭერ `Publish`-ს. ეს ფაილი GitHub-ზე ატვირთვით Firebase-ში ავტომატურად **არ** განახლდება. მხოლოდ ერთი ცვლილებაა: დასაშვები კატეგორიის ნომერი ახლა 0–23-ია (`d.category < 24`). შენს უკვე შექმნილ მომხმარებლის ანგარიშს ეს ცვლილება არ შეეხება.

## შენიშვნები
- გადახდები და GPS ჯერ არ არის ჩართული; მთავარი გვერდის გამოძახებები საცდელია.
- Firebase-ის რეალური პროფილებიდან ჩანს მხოლოდ დადასტურებული სპეციალისტები.
- კოდი განახლებულია ისე, რომ უკვე არსებული 12 კატეგორიის ინდექსები უცვლელი დარჩა.
- ეს ვერსია ცვლილებების შემოწმებისთვისაა. პირველ რიგში შეამოწმე ახალი კატეგორიები და ქვეკატეგორიები, შემდეგ ხელოსნის რეგისტრაცია.
