# HEXORA — საჯარო დემო (ვერსია 1)

HEXORA არის საქართველოს მასშტაბით სხვადასხვა ხელოსნისა და მომსახურების გამოძახების სისტემის **სატესტო ინტერფეისი**.

## გაშვება GitHub Pages-ზე

1. შექმენით Public რეპოზიტორია `hexora-web` ორგანიზაციაში `hexora-services`.
2. რეპოზიტორიის მთავარ (root) საქაღალდეში ატვირთეთ `index.html`. `README.md` არჩევითია.
3. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. გამოქვეყნების შემდეგ მისამართი იქნება `https://hexora-services.github.io/hexora-web/`.

## რა მუშაობს ამ დემოში

- ქალაქებითა და კატეგორიებით სერვისების მოძებნა, საცდელი ხელოსნების ჩამონათვალი;
- ხელოსნის საცდელი პროფილის დამატება და ონლაინ/ოფლაინ რეჟიმი;
- ვიზიტის ფასის წინასწარი ჩვენება და სატესტო გამოძახება;
- შეკვეთის მიღება → მისვლა → შესრულების მონიშვნა → მომხმარებლის დადასტურება;
- 3 ლარის **სატესტო** საკომისიო მხოლოდ დასრულებულ ვიზიტზე;
- ადგილზე არყოფნის შეტყობინება, დავის განხილვის დემო და ორმხრივი შეფასებები.

## შეზღუდვები და უსაფრთხოება

**ეს არ არის მოქმედი დაჯავშნის, ანგარიშსწორების ან გამოძახების სისტემა.**

- არ აქვს Firebase-სერვერი, ნამდვილი რეგისტრაცია, უსაფრთხო ადმინისტრატორის ავტორიზაცია, GPS თვალთვალი ან ბანკის გადახდები.
- ყველაფერი ინახება **მხოლოდ ამ მოწყობილობის ბრაუზერში** (`localStorage`), მონაცემები სხვა მოწყობილობასთან არ სინქრონდება.
- მომხმარებლის ვინაობა, ვიზიტი, მისვლა და შეფასება ამ დემოში რეალურად არ მოწმდება.
- არ შეიყვანოთ ნამდვილი მისამართები, ტელეფონები, საბანკო დეტალები ან კონფიდენციალური ინფორმაცია.
- დროებით დამატებულია `noindex`, რადგან ეს მხოლოდ სატესტო დემოა; რეალური გაშვებისთვის უნდა მოვხსნათ სათანადო SEO/უსაფრთხოების მზადყოფნის შემდეგ.

**საიტი დამოუკიდებელია Thermohut-ის, CarDoc AI-სა და სხვა არსებული პროექტებისგან.**
