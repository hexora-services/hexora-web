# HEXORA V5 — პირველი რეალური ხელოსნების კატალოგი

ეს ვერსია ამატებს Firestore-ში რეგისტრირებული **დამტკიცებული** ხელოსნების ჩვენებას კატეგორია → ქვეკატეგორია → ხელოსნები ეკრანზე.

## აუცილებელი
1. GitHub-ის `hexora-services/hexora-web` რეპოზიტორიის ფესვში ატვირთე ZIP-იდან ამოღებული ფაილები: `index.html`, `account.html`, `account.js`, `real-workers.js`, `firebase-config.js`, `firestore.rules`, `favicon.svg`.
2. Firebase Console-ში Email/Password ავტორიზაცია უნდა იყოს ჩართული; Firestore `(default)` ბაზა შექმნილი და `firestore.rules`-ის წესები **გამოქვეყნებული**.
3. Firebase Authentication → Settings → Authorized domains-ში უნდა იყოს `hexora-services.github.io`.
4. ხელოსანმა უნდა გაიაროს რეგისტრაცია და ელფოსტის დადასტურება.
5. **მხოლოდ რეალური გადამოწმების შემდეგ** Firebase Console → Firestore Database → Data → `workerProfiles` → ხელოსნის UID დოკუმენტში შეცვალე `approved` Boolean `false` → `true`. მხოლოდ ამ ადმინისტრატორის ხელით გაკეთებული მოქმედების შემდეგ გამოჩნდება პროფილი საჯარო სიაში. ჩვეულებრივ მომხმარებლებს და ხელოსანს საკუთარი თავის დამტკიცება არ შეუძლიათ Firestore Rules-ის გამო.
6. ხელოსანმა თავის პროფილში ჩართოს ონლაინ რეჟიმი, თუ მზადაა შეკვეთებისთვის. პროფილი `offline` მდგომარეობაშიც ჩანს, თუ ფილტრი „მხოლოდ ონლაინ“ არ არის ჩართული.

## უსაფრთხოება და შეზღუდვები
- რეგისტრაცია და მონაცემების შენახვა რეალურ Firebase-ზეა, მაგრამ მთავარი საიტის `შეკვეთები`, `ხელოსანი`, `დემო-ადმინი` კვლავ ბრაუზერში შენახული **დემო ფუნქციებია**. არც შეკვეთები, არც GPS და არც გადახდები ამ ეტაპზე არ იმუშავებს რეალურად.
- რეალური პროფილის ბარათებზე გამოძახების ღილაკი გათიშულია. რეალურ მომხმარებლებს ცრუ შეკვეთებს არ ვპირდებით.
- Firebase `apiKey` ვებკონფიგურაცია საჯაროა; მონაცემებს იცავს Firestore Security Rules, არა `apiKey`-ს საიდუმლოდ შენახვა.
- გამოცდისას გამოიყენე საცდელი ხელოსნის ანგარიში; არ შეცვალო ან არ წაშალო უკვე შექმნილი მომხმარებლების ანგარიშები.
- სამომავლოდ გვჭირდება უსაფრთხო ადმინისტრატორის ავტორიზაცია, შეკვეთების სერვერული დამუშავება, გადახდის პროვაიდერი, უარყოფილი ვიზიტების დავების პროცესი, რეალური GPS და კონფიდენციალურობის პოლიტიკა.
